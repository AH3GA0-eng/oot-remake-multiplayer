# hs-puppet-smooth (Hookshot): how smooth the other player's Link plays (owner 2026-11-16: "Animations seem
# a bit jittery and choppy"). A walks and runs back and forth in front of B for ~40 s; B stands and watches.
# Run: tools\autotest\run.ps1 -Runtime hookshot -Scenario hs-puppet-smooth -Lane 1
# Read B's log (A's the same with P2), every 5 s while A moves:
#   "pose: P1 limbs: uneven U (M moving frames, ...); raw R, jumps J/s; we send H/s x B bones"
# PASS (puppet-smooth): J about 0 (no bone held a frame and then jumped), "we send 30/s x 222 bones" in both
# logs (two players: every moving bone, 30 a second). An older module logs only "uneven U" (= today's raw R).
# Shots: B's at the walk/run marks show A's puppet mid-stride.
#! switches LICHII_COOP_PUPPET=1
mark start
wait 1500               # the puppets made
mark spawned
stick 0 0.5 240         # walk away from B
mark walk1
stick 0 -0.5 240        # walk back
mark walk2
stick 0 1 150           # run away
mark run1
stick 0 -1 150          # run back
mark run2
stick 1 0 120           # walk right
mark side1
stick -1 0 120          # and back
mark side2
stick 0 1 150           # run once more
mark run3
stick 0 -1 150
mark run4
wait 120
mark end
